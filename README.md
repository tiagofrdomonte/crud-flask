🐍 CRUD em Flask
Um projeto de aplicação web simples com Flask, implementando operações de Create, Read, Update e Delete (CRUD) para gerenciamento de usuários.

🚀 Funcionalidades

Cadastro de usuários
Edição de perfil
Exclusão de contas
Login e Logout com Flask-Login
Validação de formulário com WTForms
Flash messages com Bootstrap
Proteção de rotas com login obrigatório

🛠 Tecnologias usadas
Python 3.x
Flask
SQLAlchemy
WTForms
Flask-Login
Bootstrap 5
